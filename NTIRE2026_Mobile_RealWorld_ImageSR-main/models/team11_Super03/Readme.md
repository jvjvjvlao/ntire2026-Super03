🛠 Prerequisites
Before running the project, please ensure that your environment meets the following requirements:

## 1. Mandatory Requirements
These are essential for the core functionality and model loading:

pip install pytorch-lightning  # Required for loading model checkpoints

2. Optional (For Online Model Downloading)
If you do not have the Stable Diffusion 2.1 base model weights locally, you will need this to download them automatically:

pip install modelscope         # Required for online SD 2.1 base weight downloading
